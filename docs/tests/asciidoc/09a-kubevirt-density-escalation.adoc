= Test 09a — KubeVirt Density Escalation (Set It and Forget It)

_Category:_ OpenShift Virtualization — CirrOS VM Density  
_Namespace:_ `burner-escalation`  
_Escalation:_ 5 → 15 → 30 → 60 → 100 VMs  
_Duration:_ ~20–40 min  
_Difficulty:_ ⭐⭐⭐ Advanced

== What this test does

Automatically runs 5 back-to-back density rounds using lightweight CirrOS VMs. Each round creates VMs, waits for them all to reach Running state, then deletes them before proceeding to the next round. No manual intervention required.

| Round | VMs | Max Wait |
|-------|-----|----------|
| 1 | 5 | 30 min |
| 2 | 15 | 30 min |
| 3 | 30 | 30 min |
| 4 | 60 | 30 min |
| 5 | 100 | 30 min |

'''

== Prerequisites

* OpenShift cluster with OpenShift Virtualization installed
* `oc` CLI logged in with cluster-admin
* Verify image pull works: `oc debug node/<any-node> -- chroot /host crictl pull quay.io/kubevirt/cirros-registry-disk-demo:latest`

'''

== Step 1 — Namespace and RBAC

[source]
----
oc new-project burner-escalation

oc create serviceaccount kube-burner -n burner-escalation

oc create clusterrole kube-burner-virt \
  --verb=get,list,watch,create,delete,patch,update \
  --resource=virtualmachines,virtualmachineinstances,pods,namespaces,configmaps,jobs,events

oc create clusterrolebinding kube-burner-virt-escalation \
  --clusterrole=kube-burner-virt \
  --serviceaccount=burner-escalation:kube-burner
----

'''

Create `/tmp/vm-template.yml`:

[source]
----
apiVersion: kubevirt.io/v1
kind: VirtualMachine
metadata:
  name: escalation-vm-{{.Iteration}}-{{.Replica}}
  labels:
    app: burner-escalation
spec:
  running: true
  template:
    metadata:
      labels:
        app: burner-escalation
    spec:
      domain:
        cpu:
          cores: 1
        resources:
          requests:
            memory: 128Mi
        devices:
          disks:
            - name: containerdisk
              disk:
                bus: virtio
          interfaces:
            - name: default
              masquerade: {}
      networks:
        - name: default
          pod: {}
      volumes:
        - name: containerdisk
          containerDisk:
            image: quay.io/kubevirt/cirros-registry-disk-demo:latest

== Step 3 — Package into ConfigMap

[source]
----
oc create configmap escalation-config \
  --from-file=config.yml=/tmp/cirros-escalation-config.yml \
  --from-file=vm-template.yml=/tmp/vm-template.yml \
  -n burner-escalation
----

'''

== Step 4 — Launch the job

[source]
----
cat <<'EOF' | oc apply -f -
apiVersion: batch/v1
kind: Job
metadata:
  name: kb-escalation
  namespace: burner-escalation
spec:
  template:
    spec:
      serviceAccountName: kube-burner
      initContainers:
        - name: copy-config
          image: busybox
          command: ["sh","-c","cp /configmap/* /config/"]
          volumeMounts:
            - name: configmap-vol
              mountPath: /configmap
            - name: config-vol
              mountPath: /config
      containers:
        - name: kube-burner
          image: quay.io/kube-burner/kube-burner:v2.7.3
          command:
            - kube-burner
            - init
            - -c
            - /config/config.yml
            - --uuid
            - cirros-escalation-001
          volumeMounts:
            - name: config-vol
              mountPath: /config
      volumes:
        - name: configmap-vol
          configMap:
            name: escalation-config
        - name: config-vol
          emptyDir: {}
      restartPolicy: Never
EOF
----

== Force-stop a stuck or failing round

[source]
----
= Delete the job
oc delete job kb-escalation -n burner-escalation

= Delete any remaining VMs
oc delete vm -l app=burner-escalation -n burner-escalation --wait=false

= Watch deletion progress
oc get vm -n burner-escalation -w
----

'''

== Cleanup

[source]
----
oc delete job kb-escalation -n burner-escalation 2>/dev/null || true
oc delete configmap escalation-config -n burner-escalation 2>/dev/null || true
oc delete vm -l app=burner-escalation -n burner-escalation --wait=false 2>/dev/null || true
oc delete project burner-escalation
oc delete clusterrole kube-burner-virt
oc delete clusterrolebinding kube-burner-virt-escalation
----

'''

== Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| `ImagePullBackOff` | Cannot pull CirrOS image | Check registry access; use internal mirror |
| VMs stuck `Pending` | Not enough CPU/memory | Reduce `replicas` in config |
| Job pod in `Error` | YAML syntax error | `oc describe configmap escalation-config -n burner-escalation` |
| Delete round finds 0 VMs | Wrong `labelSelector` | Must be `kube-burner.io/job: r01-create` (not `kube-burner-job`) |

'''
